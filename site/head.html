The Windows support toolbox you start with one command.

Tools, app installs, tweaks and update policies in one dark / light window. Built for remote support in ScreenConnect Backstage, and works on any Windows PC.

irm hype-it-za.github.io/it-toolkit | iex

Paste into an elevated PowerShell window or the Backstage PowerShell console. It downloads the latest version to C:\ProgramData\ITToolkit and opens the toolkit. Run it again any time to update.

Older PC that shows a TLS or SSL error? Use this instead:

[Net.ServicePointManager]::SecurityProtocol='Tls12'; irm hype-it-za.github.io/it-toolkit | iex

Made for remote support

  • Runs as SYSTEM in Backstage, with no Explorer needed
  • User-session tools and tweaks reach the signed-in user, not SYSTEM
  • HTML health check, log bundle for escalation and before / after snapshots
  • Saved setups: export apps and tweaks once, apply them on every new PC
  • Ticket notes summarise the session, ready to paste
  • Optional webhook to Discord, Slack or Teams
  • Favourites, recent tools and a PS> prompt for anything else

Safe by default

  • Risky actions ask first and explain what could break
  • Cleanup only removes temp and cache files Windows rebuilds
  • A restore point is made before tweaks, and almost every tweak can be undone
  • Windows Update reset keeps the old folders as a backup
  • Logs and reports are saved in C:\ProgramData\ITToolkit

No window needed

Run tools, installs and tweaks from a script or ScreenConnect's Commands tab. The exit code is 1 if anything logged an error.

# Load once
$itk = [scriptblock]::Create((irm hype-it-za.github.io/it-toolkit))

# Everything you can run
& $itk -List

# Run tools
& $itk -Run 'Disk space', 'Safe cleanup'

# Install apps (winget IDs or app names)
& $itk -Install Google.Chrome, 7zip.7zip

# Apply a tweak (add -Undo to revert)
& $itk -Tweak 'Show file extensions'

# Apply a saved setup (apps + tweaks)
& $itk -Setup 'https://example.com/office-pc.json'

# Save an HTML health check report
& $itk -HealthCheck
