The Windows support toolbox you open with one command.

No window needed

Run tools, installs and tweaks from a script or ScreenConnect's Commands tab. The exit code is 1 if anything logged an error.

# Load once
$itk = [scriptblock]::Create((irm hype-it-za.github.io/it-toolkit))

# Everything you can run
& $itk -List

# Run tools
& $itk -Run 'Disk space', 'Safe cleanup'

# Install apps (winget IDs or app names)
& $itk -Install Google.Chrome, 7zip.7zip

# Apply a tweak (add -Undo to revert), or see which tweaks are applied
& $itk -Tweak 'Show file extensions'
& $itk -TweakStatus

# Apply a saved setup (apps + tweaks)
& $itk -Setup 'https://example.com/office-pc.json'

# Save an HTML health check report
& $itk -HealthCheck

# Check the toolkit itself works on this PC
& $itk -SelfTest

Know what you run

irm | iex runs code from the internet. This page is the installer: PowerShell ignores the web page around it and runs the script below. Read it here or on GitHub before you use it on a client's PC.

Something not working? Open Tools, then Toolkit, then Toolkit self-test. It checks permissions, PowerShell, winget, the network and more, and says what to fix.

    
Found a bug? Report it on GitHub. The form asks for the self-test output, which usually shows the cause.
